Project Overview

Keenwiix Design System is a scalable UI kit designed to unify the visual language across multiple digital products. The system includes design tokens, reusable components, and documentation — built to help teams ship faster without breaking consistency.

Problem

When teams build multiple products without a shared system, inconsistency spreads fast. Different colors, spacing, and components appear everywhere — making products feel disconnected and slowing down development.

  • Inconsistent UI across different products
  • Designers re-invent the same components
  • Developers hardcode values instead of using tokens
  • Slower onboarding for new team members

Research & Discovery

I studied the best design systems in the world — from Material Design to Polaris to Carbon — and identified the key principles that make systems succeed: strong tokens, clear documentation, and consistency over features.

Key Insights

  • Tokens are the foundation of consistency
  • Documentation is as important as components
  • Fewer components → higher adoption
  • Systems should feel calm, not overwhelming

Design Process

01

Audit & Foundation

02

Component Design

Designed 24 reusable components with variants — buttons, inputs, badges, cards.

03

Documentation

Built a live documentation site with copy-to-clipboard tokens and clear usage guidelines.

04

Development

Implemented with pure HTML/CSS/JS — framework-agnostic, fast, accessible.

05

Refinement

Tested across devices, refined interactions, and polished the final system.
